Engineered for Performance

Clean, reliable video and audio downloads without bloated installers, tracking, or popups.

Non-Blocking Async UI

The user interface never freezes. Worker threads coordinate smoothly through a thread-safe EventBus.

4K UHD & Multi-Format Audio

Download up to 4K UHD (2160p), 2K, 1080p, or extract studio-quality audio in MP3, M4A, FLAC, and original audio streams with zero loss.

1-Click FFmpeg Setup

Missing FFmpeg? Download and auto-configure it with a single click directly inside the app with zero manual steps.

SQLite History Vault

Keep a searchable local record of downloaded media. Play files directly or reveal them in Windows Explorer.

Safe Windows Filesystem

Sanitizes forbidden characters and Windows device names (CON, PRN). Prevents accidental overwrite collisions.

Open Source & Extensible

MIT Licensed. Full pytest suite, Ruff code style, and automated GitHub Actions CI workflow for easy contributions.

For Developers

Run from Source Code

Run each command in your terminal one by one:

1. $ git clone https://github.com/anujkantx/yt-downloader.git
2. $ cd yt-downloader
3. $ python -m venv .venv
4. $ .\.venv\Scripts\Activate.ps1
5. $ pip install -r requirements-dev.txt
6. $ python main.py
